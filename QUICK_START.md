# Quick Start

## 🚀 One-Command Setup
```bash
chmod +x setup.sh && ./setup.sh
```

## 🎯 Usage
```bash
fe_local  # Run from anywhere!
```

## 🗑️ Uninstall
```bash
./uninstall.sh
```

## 📋 What it does
- Builds optimized binary with PyInstaller
- Installs globally to `/usr/local/bin/fe_local`
- Handles macOS Gatekeeper automatically
- Provides easy uninstall option

## 🔧 Manual Setup (Alternative)
```bash
# Build only
./build.sh

# Install globally
./install.sh
```
